Introducción a Variables en Python

Aprende cómo almacenar datos en tu programa utilizando variables, el bloque de construcción fundamental de cualquier script de Python.

Una variable es como una caja etiquetada donde puedes guardar un valor. En Python, no necesitas declarar el tipo de variable antes de usarla; el lenguaje lo infiere automáticamente cuando le asignas un valor.

¿Cómo crear una variable?

Para crear una variable, simplemente elige un nombre y usa el signo igual = para asignarle un valor. El nombre de la variable va a la izquierda y el valor a la derecha.

ejemplo_variables.py
# Creando variables
nombre = "Ana"          # Una cadena de texto (string)
edad = 25               # Un número entero (integer)
altura = 1.68           # Un número decimal (float)
es_estudiante = True    # Un valor booleano (boolean)
print(f"Hola, soy {nombre} y tengo {edad} años.")

Reglas para nombrar variables

Python tiene algunas reglas simples pero estrictas para los nombres de variables:

  • Deben comenzar con una letra (a-z, A-Z) o un guion bajo (_).
  • No pueden comenzar con un número.
  • Solo pueden contener caracteres alfanuméricos y guiones bajos (A-z, 0-9, y _).
  • Los nombres distinguen entre mayúsculas y minúsculas (edad, Edad y EDAD son tres variables diferentes).

info Tip Pro

En Python, la convención es usar snake_case para los nombres de variables. Esto significa usar todas las letras en minúscula y separar las palabras con guiones bajos. Ejemplo: mi_variable_favorita.

Reasignación de Variables

Las variables en Python son dinámicas. Esto significa que puedes cambiar el valor de una variable en cualquier momento, e incluso cambiar su tipo de dato (aunque esto último no siempre es recomendable por legibilidad). 

x = 10       # x es un entero
print(x)
x = "diez"   # Ahora x es una cadena de texto
print(x)
